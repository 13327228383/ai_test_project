# 规模根因诊断 —— 30 万行是怎么来的（2026-10-04）

> 触发：用户质疑「特斯拉自动驾驶也才 30 万行，测试引擎也 30 万行，不正常」。
> 结论：**质疑成立**。本文用 AST 级全量测量定位膨胀机制，给出量化收敛路径。

## 一、对标

| 系统 | 规模 | 说明 |
|:---|---:|:---|
| Playwright 本体 | ~20 万行 | 浏览器自动化**基础设施**（我们是它的使用方） |
| pytest | ~3 万行 | 测试框架本体 |
| 本引擎 src/ | 29.3 万行（净代码 23.8 万） | 包着 Playwright 的编排层 |

正常量级推算：需求接入+AI 用例生成+执行编排+三轨验证+报告 ≈ **8–13 万行**。
本仓超配 **2–3 倍**。

## 二、测量数据（AST 全量，2026-10-04）

| 指标 | 数值 | 含义 |
|:---|---:|:---|
| 净代码行（去注释/空行） | 237,914 | 函数 6,025 / 类 550 |
| **≥100 行巨型函数** | **521 个 = 103,850 行 = 净代码 44%** | `_execute_one_intent` 单函数 1,466 行 |
| **try/except 机器内代码** | **~108,500 行 ≈ 净代码 46%** | 5,200 个 try 块；try 密度 0.86/函数 |
| 语义同构克隆家族 | ≈ 0（仅 1 个 45 行小家族） | **不是复制粘贴堆大的** |
| 死代码 / 字面重复 / 叙事注释 / 静默吞噬 | 已清零（见 §6 审计链） | 卫生层干净 |
| 最大函数解剖 | 1,466 行 = 37 try + 36 处理器 + 89 if + 73 日志 + **0 内嵌函数** | 平均每 40 行裹一层防御 |

## 三、根因链（可复现的证据链）

```
追加式修复开发文化（每个缺陷在"症状层"补一段）
  → 修复全部内联进现有函数（无拆分纪律：单函数 0 个内嵌函数、89 个 if）
  → 每段修复自带 try/except+log+fallback 防御三件套
  → 521 个上帝函数持有 44% 代码；防御机器占 46%
  → 30 万行。它不是"写多了"，是"从未收拢过"。
```

对照排除项：**不是**复制粘贴（克隆≈0）、**不是**死代码（已清零）、**不是**注释
（注释+docstring 仅占 18%）。唯一机制就是**防御样板在上帝函数内的逐层累积**。

## 四、此前处置的判定

必要但不完整。此前清掉的是卫生层（死代码/重复/叙事/静默），属于"止血"；
结构层（上帝函数 + 防御机器）才是体量主因，且当时缺回归网不能动。
现两道金样本 + 链路哨兵已就位，具备动刀条件。

## 五、量化收敛路径（目标：净代码 23.8 万 → 14–16 万）

| 层 | 动作 | 预计净省 | 前置 |
|:---|:---|---:|:---|
| L1 防御原语收敛 | ✅ 已实施（提交 ef17a94）：`src/core/guarded.py` 原语 + AST 机改 1,461 位点/340 文件（三种安全模式，含默认值上提/嵌套安全/入口引导修正）。实测净省 ~3.2k 行——**低于预估**，因剩余样板藏在 return-in-handler（fail-closed）/多 handler/复杂控制流里，机器不可安全转换，须先经 L2 相位拆分 | ~3.2k 已实现；剩余并入 L2 | 已完成 |
| L2 巨型函数分解 | TOP 521 个逐个拆相位函数（`_execute_one_intent` 1466 → 相位化 ~8 函数） | 行数本身不降，但使 L1 可实施、L3 可见 | L1 |
| L3 校验器表驱动 | 40+ 个 `_verify_*` 各自独立文件 → 一张表 + 一个执行器 | 1–2 万 | L2 |
| L4 执行层合并 | browser_core/single_mixins 与 browser_tools/execution 两套编排各自重复装配 | 1–2 万 | L1 |
| L5 后端收敛 | 42,630 行 routes（268 端点）按资源合并 + 表驱动 fetcher | 0.8–1.5 万 | — |
| L6 架构级（需裁决） | 双规则体系单内核；`step4_executor` 与 `empirical` 双执行链合一 | 1–2 万 | L1–L2 |

L1–L5 是**工程收敛**（保持全部能力），L6 涉及能力形态需产品裁决。
按此路径 238k → ~15 万（净）可达；到 Playwright 量级（<10 万）需推倒式重设计，
不属于渐进收敛范畴，须明示。

## 六、纪律

- 每次动刀：金样本对比 + 401 套件 + 三门禁 + 链路实证（已固化在 CI chain-smoke）。
- 禁止在收敛中夹带行为变更；语义等价用金样本证明。
- 上帝函数拆解一律"先拆相位、原样搬运"，收敛样板单独一批提交（可回滚）。
