1. Step1 源接入（真实拉取，≥1 失败 + ≥1 跳过以点亮 total_failed/total_skipped）
2. Step2 AI 拆解（真实 LLM 调用，高/中/低置信度样本齐全）
3. Step3 建模（支配度/复杂度/质量分齐全）
4. Step4 单浏览器 AI 循环（真跑 AI 动作，不许全 replay）
5. Step4 并行执行模式至少 1 run
6. 四条验证轨道（cross_check/deep_check/fuzzy_match/ground_truth）各 ≥1 run
7. 浏览器仪表（dom_sizer/dom_diff/region_tree/fcp/visual_baseline/cdp_browser）开启
8. 自愈/降级路径（self_heal/click_fallback/guard_reject/flaky_guard）至少各触发 1 次
9. token 预算与治理（token_budget/harness_governance/tool_mode）
10. case_runner 路径（pipeline_ext）+ 增量重生成 + 哈希复用
11. Step5 报告 + scorecard + manual_retest
